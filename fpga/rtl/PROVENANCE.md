# Provenance

Modules and files copied from [retro68k](https://github.com/jonsole/retro68k) (design plan, branch 12, "RTL reuse"). Copy only from a committed retro68k state. Later retro68k fixes are ported by hand: compare its git log since the commit below.

Files that moved to retro-hw (the shared cores, `fpga/retro-hw`; design plan, branch 23) are recorded in `fpga/retro-hw/PROVENANCE.md`: `sram_ctl`, `fifo8`, `tmds_encoder`, `dmac`, `timebase`, `layer_pix`, `sprite_pix`, the platform files and the SRAM, FT232H and PS/2 models. The rows below for `serial.v`, `audio.v`, `ps2kb.v`, `sprites.v`, `copper.v` and `dmx.v` describe the wrappers that stay here.
