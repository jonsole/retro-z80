# Interrupts and timers

> retro-z80 reference for AI models writing Z80 code. Register tables between `<!-- gen:NAME -->` markers are generated from `fpga/regmap.def` by `python3 tools/llm_docs.py interrupts-timers`: never edit them by hand. Every ```asm block assembles on its own (`python3 tools/llm_docs.py --asm interrupts-timers`); general rules (port form, `_P`/`_M`/`_B` names, program map, register page) are in [system.md](system.md).

**Built on the KS2:** the interrupt controller, TIME, the four timers, the watchdog and the NMI set of the interrupt pages, yes. Sources wired: 0 VBLANK, 1 LINE, 2 COPPER (not in a `--no-copper` build), 3 VIDERR, 4 BLT (not in a `--geom` build), 9 AUDIO, 11–14 TIMER0–3, 15 SERIAL, 17 KEYB, 18 SOFT. Sources 5–8, 10, 16, 19, 20 request nothing (INTRAW reads 0). **Not built:** the maskable interrupt pages (IPCTL, IPMASK, IPDEPTH, IPRESTORE, IPn … IPSAVnW read `0xFF`, maskable interrupts switch nothing).

## What it does

One /INT line, 21 sources with fixed priority (lower number first), IM 2 vector = VECBASE + 2 × source. Requests are **levels** from the units' flags; the controller keeps no flags except SOFT. NMI from the Multiface button, the PC's BREAK and the debug unit. TIME counts microseconds; four 16-bit timers with 16-bit prescalers; a watchdog.

## Enable

An interrupt reaches the CPU only when all four are on:

| # | Switch | Where |
|---|--------|-------|
| 1 | The unit's enable for its flag | VIDINTEN, COPCON.IRQEN, DMXINTEN, AUDINTEN, TMRn_CTRL.IRQ, SERIRQEN, KBIRQEN |
| 2 | The source's INTENA bit | INTENA0–2, set/clear, bit 7 = SETCLR: byte `INTR_name`, bit `INTB_name` |
| 3 | INTCON.MASTER | `INTCON_P`, bit 0 |
| 4 | The CPU | `IM 2` (never IM 0), `EI` |

At program entry (boot ROM): IM 2, DI, I = `0x1F`, VECBASE = `0xD0` (the ROM's table at `0x1FD0`, whose one handler turns off whatever source fires), INTENA all clear, MASTER clear, NMICON both on, NMICTL = `0x01`.

### Controller (page `0x00`, `0x00`–`0x0E`)

| `0x00` | `0x0000` | `INTCON` | 1 | RW | MASTER 0 |

| `0x0B` | `0x0B00` | `SOFTINT` | 1 | S | CLR 1, SET 0 |
| `0x0C` | `0x0C00` | `INTID` | 1 | R | SRC 4–0 |
| `0x0D` | `0x0D00` | `NMICON` | 1 | RW | USBEN 1, BUTTONEN 0 |
| `0x0E` | `0x0E00` | `NMISTAT` | 1 | W1C | USB 1, BUTTON 0 |
<!-- /gen:intc -->

- INTENAn: bit 7 = 1 sets the bits written as 1, bit 7 = 0 clears them; bits written 0 unchanged. Reads give the enables (bit 7 reads 0). Never read-modify-write.
- INTPENDn = raw & INTENA & MASTER; INTRAWn = request lines. Read live, no capture.
- INTID: the source chosen at the last acknowledge (0–20, or 23). Valid until the next acknowledge, i.e. until after the handler's `EI`. Use it for IM 1 dispatch.
- VECBASE: bit 0 always 0. Vector byte = (VECBASE + 2n) mod 256; a VECBASE above `0xD0` wraps the 48-byte table round the page.
- SOFTINT: write SET (bit 0) to raise SOFT, CLR (bit 1) to drop it; reads `0x00`. INTRAW2 bit 4 shows SOFT.
- NMICON reset `0x03` (BUTTONEN, USBEN). NMISTAT: W1C flags of which NMI came. The debug unit's NMI has no NMICON bit.
- `0x0F` is not answered (`0xFF`).

- Built: NMICTL (reset `0x01`: EN), NMIMASK (reset `0x01`: window 0), NMICAPPC, NMICAPSP, NMIPn/NMIPnW (NMIP0 = `0x3FF` boot ROM page 3, NMIP0W = `0x0FF` monitor workspace), NMISAVn/NMISAVnW. Page registers follow the MMU rule: byte 0 held, byte 1 commits; a read-page commit also sets the write page.
- Not built: IPCTL, IPMASK, IPDEPTH, IPRESTORE, IPn, IPnW, IPSAVn, IPSAVnW (read `0xFF`).
- NMI stack capture is always on: the NMI's two pushes write nothing; the return address goes to NMICAPPC, the old SP to NMICAPSP; `RETN` pops from NMICAPPC. Writing NMICAPPC changes where `RETN` goes.
- NMICTL.INNMI (read only) is 1 from NMI entry to its `RETN`; /NMI is held off meanwhile (an NMI never nests).

### TIME and the watchdog (page `0x00`)

<!-- gen:time-wd -->
<!-- Generated by tools/llm_docs.py from fpga/regmap.def; do not edit by hand. -->
| Offset | Port (`_P`) | Name (bytes) | Bytes | Access | Fields, whole-value bits (bK: bits in byte K) |
|--------|-------------|--------------|-------|--------|------------------------------------------------|
| `0x20` | `0x2000` | `TIME` (TIME0/TIME1/TIME2/TIME3) | 4 | R,CAP | whole value |
| `0x48` | `0x4800` | `WDCTRL` | 1 | RW,LOCK | LOCK 1, EN 0 |
| `0x49` | `0x4900` | `WDTIME` (WDTIME0/WDTIME1) | 2 | RW,LOCK | whole value |
| `0x4B` | `0x4B00` | `WDKICK` | 1 | S | – |
<!-- /gen:time-wd -->

- TIME: microseconds since power-on (not reset by other resets), wraps after 71.6 minutes. **Read TIME0 first**: it captures all 32 bits; TIME1–3 then come from the capture. Interrupts off around it if a handler also reads a capturing register (one capture per CPU).
- WDTIME: milliseconds between kicks, reset 1000 (`0x03E8`); 0 acts as 1. Fires between WDTIME and WDTIME + 1 ms after the last kick.
- WDCTRL.EN on starts the time; any WDCTRL write restarts it. WDCTRL.LOCK (set it in the same write as EN) makes WDCTRL and WDTIME read only until reset.
- WDKICK: `0x5A` (`WDKICK_MAGIC`) kicks; **any other value resets at once** while EN. Ignored while off. Reads `0x00`.
- Timeout: full reset, RESETWHY.WATCHDOG set. Off after every reset.

### Timers TMR0–TMR3 (page `0x00`)

<!-- Generated by tools/llm_docs.py from fpga/regmap.def; do not edit by hand. -->
4 elements, `0x08` bytes apart: element n at `0x28` + n × `0x08`. Bases (offset/port): TMR0 `0x28`/`0x2800`, TMR1 `0x30`/`0x3000`, TMR2 `0x38`/`0x3800`, TMR3 `0x40`/`0x4000`.

| +Off | Name (element 0; bytes) | Port, element 0 | Bytes | Access | Fields, whole-value bits (bK: bits in byte K) |
|------|-------------------------|-----------------|-------|--------|------------------------------------------------|
| `0x00` | `TMR0_CTRL` | `0x2800` | 1 | RW | IRQ 4, SRC 3–2, REPEAT 1, EN 0 |
| `0x01` | `TMR0_PRESCALE` (TMR0_PRESCALE0/TMR0_PRESCALE1) | `0x2900` | 2 | RW | whole value |
| `0x03` | `TMR0_RELOAD` (TMR0_RELOAD0/TMR0_RELOAD1) | `0x2B00` | 2 | RW | whole value |
| `0x05` | `TMR0_COUNT` (TMR0_COUNT0/TMR0_COUNT1) | `0x2D00` | 2 | RW,CAP | whole value |
| `0x07` | `TMR0_STAT` | `0x2F00` | 1 | W1C | UNDER 0 |

Names: `TMR0_X` … `TMR3_X` (offset), `_P` (port); `TMR_X` is the offset inside an element (add to `TMRn`).
<!-- /gen:timers -->

| CTRL field | Value | Meaning |
|------------|-------|---------|
| EN (0) | 1 | Running. Cleared by hardware at a one-shot underflow. 0→1 restarts the prescaler (first SRC 0 period full length) |
| REPEAT (1) | 1 / 0 | Repeating (reload COUNT from RELOAD) / one-shot (stop with COUNT 0) |
| SRC (3–2) | 0 | 100 MHz ÷ (PRESCALE + 1) |
| | 1 | Beam line start (every 32 µs, 625 a frame) |
| | 2 | Frame start (every 20 ms, with VIDSTAT.VBLANK) |
| | 3 | Underflow of the previous timer (timer 0 counts timer 3): chaining |
| IRQ (4) | 1 | Request TIMERn while STAT.UNDER |
| 7–5 | 0 | Reserved |

- Underflow: on the tick after COUNT = 0. So COUNT = n underflows after n + 1 ticks; repeating period = (PRESCALE + 1) × (RELOAD + 1) × 10 ns at SRC 0.
- STAT.UNDER (bit 0) is sticky W1C and set at every underflow, IRQ or not, so it can be polled.
- COUNT bytes are written straight into the counter: stop the timer first. RELOAD is used only at the next underflow (safe to change while running).
- Reading COUNT0 captures COUNT; read COUNT1 next.
- All registers of a timer are in page `0x00`: C stays `0x00`, step B (`LD B,TMR0_STAT`, `INC B`).
- Reset: all 0, stopped.

| Want | SRC | PRESCALE | RELOAD / COUNT | Mode |
|------|-----|----------|----------------|------|
| 1 µs tick | 0 | 99 | – | – |
| 1000 Hz | 0 | 99 | 999 | repeat, IRQ |
| 100 Hz | 0 | 99 | 9,999 | repeat, IRQ |
| 50 Hz free of the frame | 0 | 99 | 19,999 | repeat, IRQ |
| 10 Hz (board-tested, Example 2-3) | 0 | 9,999 | 999 | repeat, IRQ |
| Every 3 frames | 2 | – | 2 | repeat, IRQ |
| After n lines | 1 | – | COUNT n − 1 | one-shot |
| 3.57 MHz T-states | 0 | 27 | COUNT 65,535 | one-shot; elapsed = 65,535 − COUNT |
| 1 Hz | timer 0 at 1000 Hz; timer 1 SRC 3, RELOAD 999 | | | repeat, IRQ on timer 1 |

## Data structures

**IM 2 table:** 24 words at `I × 256 + VECBASE`, entry n = handler for source n; entries 21, 22 never used; entry 23 = NONE (spurious). Put it in the program's own SRAM (with the ROM in window 0, `I` must not point into `0x00xx`–`0x1Fxx`). `0x9FD0` (I = `0x9F`, VECBASE = `0xD0`) is what the examples use.

## Recipes

IM 2 set-up with VBLANK and a handler (from Example 2-1, run on the KS2):

```asm
TABLE   equ     0x9FD0                  ; I = 0x9F, VECBASE = 0xD0

start:  di
        ld      hl,TABLE                ; every entry to the spurious handler ...
        ld      b,24
.fill:  ld      (hl),low spurious
        inc     hl
        ld      (hl),high spurious
        inc     hl
        djnz    .fill
        ld      hl,vbl                  ; ... then the one this program uses
        ld      (TABLE+2*INT_VBLANK),hl
        ld      a,high TABLE
        ld      i,a
        ld      bc,VECBASE_P
        ld      a,low TABLE
        out     (c),a
        im      2
        ld      bc,VIDSTAT_P            ; clear an old VBLANK first
        ld      a,VIDSTAT_VBLANK_M
        out     (c),a
        ld      bc,VIDINTEN_P           ; 1. the unit's enable
        in      a,(c)
        or      VIDINTEN_VBLANK_M
        out     (c),a
        ld      bc,INTENA0_P+(INTR_VBLANK<<8)
        ld      a,INTENA_SETCLR_M|(1<<INTB_VBLANK)
        out     (c),a                   ; 2. the controller's enable
        ld      bc,INTCON_P
        ld      a,INTCON_MASTER_M
        out     (c),a                   ; 3. master
        ei                              ; 4. CPU
.main:  jr      .main

vbl:    push    af                      ; 50 times a second
        push    bc
        ld      bc,VIDSTAT_P
        ld      a,VIDSTAT_VBLANK_M
        out     (c),a                   ; clear the cause BEFORE EI (level-sensitive)
        ld      hl,frames
        inc     (hl)
        pop     bc
        pop     af
        ei
        reti

spurious:
        ei                              ; NONE (23), or an unexpected source
        reti
frames: db      0
```

Turn a source off (and put the ROM's table back before returning to the monitor):

```asm
        di
        ld      bc,INTCON_P
        xor     a
        out     (c),a                   ; master off
        ld      bc,INTENA0_P+(INTR_VBLANK<<8)
        ld      a,1<<INTB_VBLANK        ; SETCLR 0: clear this bit only
        out     (c),a
        ld      a,0x1F                  ; the ROM's table again
        ld      i,a
        ld      bc,VECBASE_P
        ld      a,0xD0
        out     (c),a
```

Software interrupt: do the urgent part in a handler, the slow part later (SOFT is served after every lower-numbered source):

```asm
        ld      bc,SOFTINT_P
        ld      a,SOFTINT_SET_M         ; raise SOFT (needs INTENA2 bit INTB_SOFT and MASTER)
        out     (c),a
soft:   push    af                      ; the SOFT handler
        push    bc
        ld      bc,SOFTINT_P
        ld      a,SOFTINT_CLR_M
        out     (c),a                   ; clear first, so a new SET while it runs is kept
        pop     bc
        pop     af
        ei
        reti
```

IM 1 dispatch through INTID (only with an own page in window 0; the ROM's `0x0038` is a trap):

```asm
isr38:  push    af
        ld      a,INTID                 ; register number on A15-A8
        in      a,(SYSPAGE)             ; source 0-20, or 23
        pop     af
        ei
        reti
```

Timer 0 at 10 Hz with its interrupt (Example 2-3; handler `tick` must be in the IM 2 table at `TABLE+2*INT_TIMER0`):

```asm
        ld      bc,TMR0_CTRL_P          ; C = 0x00 for the whole timer
        xor     a
        out     (c),a                   ; 1. stop
        ld      b,TMR0_STAT
        ld      a,TMR_STAT_UNDER_M
        out     (c),a                   ; 2. no old underflow
        ld      b,TMR0_PRESCALE0
        ld      hl,9999                 ; 3. 100 MHz / 10,000 = 10 kHz
        out     (c),l
        inc     b
        out     (c),h
        inc     b                       ;    RELOAD0
        ld      hl,999                  ;    / 1,000 = 10 Hz
        out     (c),l
        inc     b
        out     (c),h
        inc     b                       ;    COUNT0: the first period too
        out     (c),l
        inc     b
        out     (c),h
        ld      b,INTENA0+INTR_TIMER0   ; 4. the controller
        ld      a,INTENA_SETCLR_M|(1<<INTB_TIMER0)
        out     (c),a
        ld      b,INTCON
        ld      a,INTCON_MASTER_M
        out     (c),a
        ld      b,TMR0_CTRL             ; 5. go: repeating, with its interrupt
        ld      a,TMR_CTRL_EN_M|TMR_CTRL_REPEAT_M|TMR_CTRL_IRQ_M
        out     (c),a
        ei
tick:   push    af
        push    bc
        ld      bc,TMR0_STAT_P
        ld      a,TMR_STAT_UNDER_M
        out     (c),a                   ; clear the cause
        pop     bc
        pop     af
        ei
        reti
```

Timer as a polled one-shot delay (no interrupt): 2 s timeout:

```asm
        ld      bc,TMR1_CTRL_P
        xor     a
        out     (c),a                   ; stop
        ld      b,TMR1_STAT
        ld      a,TMR_STAT_UNDER_M
        out     (c),a
        ld      b,TMR1_PRESCALE0
        ld      hl,49999                ; 0.5 ms ticks
        out     (c),l
        inc     b
        out     (c),h
        ld      b,TMR1_COUNT0
        ld      hl,3999                 ; 4,000 ticks
        out     (c),l
        inc     b
        out     (c),h
        ld      b,TMR1_CTRL
        ld      a,TMR_CTRL_EN_M         ; one-shot, SRC 0, no IRQ
        out     (c),a
        ld      b,TMR1_STAT
.wait:  in      a,(c)
        and     TMR_STAT_UNDER_M
        jr      z,.wait
```

Read TIME (µs) into DEHL:

```asm
time:   di
        ld      bc,TIME0_P              ; C = 0x00
        in      l,(c)                   ; TIME0: captures all 32 bits
        inc     b
        in      h,(c)                   ; TIME1..3 from the capture
        inc     b
        in      e,(c)
        inc     b
        in      d,(c)
        ei
        ret
```

Watchdog: 500 ms, kicked once a frame from the main loop (Example 2-4):

```asm
        ld      bc,WDTIME0_P
        ld      hl,500
        out     (c),l
        inc     b
        out     (c),h
        ld      bc,WDCTRL_P
        ld      a,WDCTRL_EN_M           ; | WDCTRL_LOCK_M to make it permanent until reset
        out     (c),a
.frame: ld      bc,VIDSTAT_P            ; wait for the next frame
        ld      a,VIDSTAT_VBLANK_M
        out     (c),a
.wait:  in      a,(c)
        and     VIDSTAT_VBLANK_M
        jr      z,.wait
        ld      bc,WDKICK_P
        ld      a,WDKICK_MAGIC          ; 0x5A only: any other value resets at once
        out     (c),a
        jr      .frame
```

## Pitfalls and limits

- **Clear the cause before `EI`**: requests are levels; an uncleared source re-enters at once. Turning a source off in INTENA does not clear its flag; clear the unit's flag before enabling, or an old event fires at once.
- VBLANK is level-sensitive too: a Spectrum-style handler that does not clear VIDSTAT.VBLANK loops. The ROM's own table turns off any source that fires, so a source enabled without your own table is silently switched off.
- Never use IM 0 (the controller always drives a vector byte). Set `IM 2` before the first `EI`.
- With the ROM in window 0, `0x0038` is the ROM's trap: IM 1 needs the program's own page in window 0 (and then no ROM calls).
- I must point at the program's SRAM, never `0x00`–`0x1F` (ROM window). I = 0 is reserved for the ROM's self-test.
- `RETI` is not required by the controller (`EI`; `RET` works). Nesting: there is no in-service state; to let only higher-priority sources in, clear the higher-numbered INTENA bits, `EI`, and set them again before return.
- Latency at 20 MHz: worst 2.1 µs (IM 2) plus code run with interrupts off. A ROM call (PUTC, scroll) can hold interrupts off for up to 150 µs (PUTC 12 clears the whole map: about 5 ms). Pixel-exact effects belong to the copper ([copper.md](copper.md)), not to a LINE handler.
- One capture per CPU: a handler that reads TIME0, TMRn_COUNT0, BEAMPOS, FRAMECOUNT or another capturing register spoils the main program's half-done capture. Read with interrupts off, or with `LD HL,(nn)` through the register page.
- Watchdog: kick from the main loop, never from a handler. A wrong WDKICK value resets immediately. The monitor's ROM calls that wait (GETC, GETLINE) kick a running watchdog.
- An NMI (button, PC BREAK, a breakpoint) enters the monitor through NMI page 3 by default; a program that changes NMICTL/NMIMASK/NMIP0 breaks the bridge's debugging. Leave the NMI set alone.
- A debug single step holds /INT off for the step unless DBGCTL.STEPINT.
- Maskable interrupt pages are not built: `IPCTL` writes do nothing.
