Every ```asm block assembles on its own (`python3 tools/llm_docs.py --asm sound`); general rules are in [system.md](system.md).

**Built on the KS2:** yes: 4 channels with interpolation and read-back, plus the port `0xFE` beeper, on the jack (left, right) and the internal speaker (mono). `examples/sound/tone.asm` has been heard on the board.

## What it does

Four sample channels. Each plays a block of 8- or 16-bit signed PCM from SRAM by itself, resampled to one output rate (default 48.008 kHz) at any pitch (4.16 fixed-point step), with its own left and right volume 0–64, looping or queuing the next block, or one-shot. The four are summed, the beeper added with clipping, and three sigma-delta DACs drive the board. No CPU work while a block plays.

## Enable

A channel plays only while **DMACON.DMAEN, DMACON.AUDEN and its AUDDMA bit** are all set (all 0 after reset).

| Step | Write |
|------|-------|
| 1 | Channel registers: CTRL, LC, LEN, STEP, VOL (they have **no reset values**: write all five) |
| 2 | `AUDDMA` with SETCLR (bit 7) and the channel bits: `AUDDMA_SETCLR_M \| 0x03` enables channels 0 and 1 |
| 3 | `DMACON`: `DMACON_SETCLR_M \| DMACON_DMAEN_M \| DMACON_AUDEN_M`. Channels start at the next output sample |
| Interrupt (optional) | AUDINTEN bits, INTENA bit for source 9 (`INT_AUDIO`), INTCON.MASTER, IM 2 (vector VECBASE + 18) |

Enabling a channel (the last of the three bits to be set) starts it from its registers. Clearing AUDEN stops all four; setting it again restarts every channel whose AUDDMA bit is set. AUDDMA is set/clear: never read-modify-write it.

| Register | Notes |
|----------|-------|
| AUDRATE | Output rate = 100 MHz ÷ RATE. Reset 2083 = 48.008 kHz; 2268 = 44.092 kHz. Below 200 acts as 200. Bytes act as written |
| AUDSTAT | CH bit n (sticky, W1C): channel n took LC/LEN (it started or reached a block's end), or its one-shot block ended. ACTIVE bit 4 + n (live, read only): channel n playing. A write of 1 clears CH even if the channel sets it in the same clock (that event's interrupt is lost) |
| AUDINTEN | Bit n: AUDSTAT.CH bit n raises source 9 |
| AUDSTART | Strobe: bit n (re)starts channel n from its registers at the next output sample, even while playing; does nothing to a channel not enabled. Reads 0 |
| AUDSTOP | Strobe: bit n stops channel n at once (ACTIVE clears at once). Reads 0 |
| AUDDMA | Set/clear channel enables (bit 7 SETCLR). Reads the enables. Reset 0 |
| AUDn_CTRL | BITS16 (1): 16-bit samples. NEAREST (2): no interpolation (hold each sample). ONESHOT (3): play the block once and stop. Bits 0 and 7–4 read 0 |
| AUDn_LC | Physical byte address of the block (even for 16-bit). Taken only when a block starts, and for the interpolation join at a block's end |
| AUDn_LEN | Block length in **samples** (not bytes). Taken when a block starts. 0 stops the channel |
| AUDn_STEP | Samples advanced per output sample, 4.16 fixed point: `0x10000` = 1. Up to just under 16. A sample recorded at rate r, played at its own pitch: STEP = r × 65536 / 48008 (22,050 Hz → `0x7596`). A wave of N samples per cycle at frequency f: STEP = f × N × 65536 / 48008 |
| AUDn_VOL | R volume in byte 0 (`AUDn_VOL0`), L volume in byte 2 (`AUDn_VOL2`), 0–64 each (above 64 acts as 64). Byte 1 reads 0 |
| AUDn_POS | Sample index in the current block. Read `AUDn_POS0` first: it captures all three bytes |

- CTRL, STEP and VOL act from the next output sample; LC and LEN only when the channel next starts a block.
- Channel registers live in a RAM that reset does not clear (after power-on: CTRL 0, LC 0, LEN 0, STEP `0x10000`, VOL 0; after a later reset, whatever was last written). Every reset stops all channels and sets AUDRATE 2083, AUDSTAT, AUDINTEN, AUDDMA 0 and the beeper bit 0; DMACON clears too.
- Reading a channel register is answered a clock later; the CPU sees no difference.

## Data structures

| Format | CTRL.BITS16 | Layout in SRAM | LC |
|--------|-------------|----------------|----|
| 8-bit | 0 | Signed bytes, in address order (`db`) | Any byte address |
| 16-bit | 1 | Signed little-endian words (`dw`) | Even |

Mixer (per side): Σ(sample16 × volume) ÷ 256, where an 8-bit sample is shifted up by 8. One channel at volume 64 uses a quarter of the output range. Then the beeper (port `0xFE` bit 4) adds −`0x2000` when 0 and +`0x2000` when 1, and the sum is clipped to 16 bits. Mono (speaker) = (L + R) ÷ 2.

Interpolation: s = s0 + (s1 − s0) × frac ÷ 65536; at a block's last sample s1 is the first sample of the block to come (LC as it then stands), so loops join smoothly. NEAREST: s = s0.

| To get | Do |
|--------|----|
| A loop | Write LC and LEN once, start: the block repeats |
| Intro then loop | Write the whole sample, start; when the channel's AUDSTAT bit sets, write the loop part's LC and LEN, clear the bit |
| A queue | Each time the AUDSTAT bit sets, write the next block's LC/LEN |
| One-shot | CTRL.ONESHOT, then start; it stops at the end and sets its AUDSTAT bit. Replay with AUDSTART |
| Cut off and play another | Write LC, LEN, then AUDSTART bit n |

## Recipes

Two channels playing a 32-sample sine, looped: A (440 Hz) on the left, C♯ (554 Hz) on the right (from `examples/sound/tone.asm`, which runs on the KS2):

```asm
STEP_A  equ     19222                   ; 440.0 Hz: 440 * 32 / 48008 * 65536
STEP_CS equ     24218                   ; 554.4 Hz

    MACRO WREG xp, xv                   ; write xv to register port xp
        ld      bc,xp
        ld      a,xv
        out     (c),a
    ENDM
    ; One channel: CTRL 0 (8-bit, interpolated, looped), LC, LEN, STEP, VOL R, L.
    ; ctrl + 0x0400 is the port of the register 4 bytes on (same page).
    MACRO CHAN ctrl, lc, len, step, vr, vl
        WREG    ctrl, 0
        WREG    ctrl + 0x0400, low (lc)
        WREG    ctrl + 0x0500, high (lc)
        WREG    ctrl + 0x0600, (lc) >> 16
        WREG    ctrl + 0x0800, low (len)
        WREG    ctrl + 0x0900, high (len)
        WREG    ctrl + 0x0A00, 0
        WREG    ctrl + 0x0C00, low (step)
        WREG    ctrl + 0x0D00, high (step)
        WREG    ctrl + 0x0E00, (step) >> 16
        WREG    ctrl + 0x1000, vr       ; VOL byte 0: right
        WREG    ctrl + 0x1100, 0
        WREG    ctrl + 0x1200, vl       ; VOL byte 2: left
    ENDM

start:  CHAN    AUD0_CTRL_P, wave, 32, STEP_A, 0, 48
        CHAN    AUD1_CTRL_P, wave, 32, STEP_CS, 48, 0
        WREG    AUDDMA_P, AUDDMA_SETCLR_M | 0x03
        WREG    DMACON_P, DMACON_SETCLR_M | DMACON_DMAEN_M | DMACON_AUDEN_M
        ret

wave:   db      0, 20, 38, 56, 71, 83, 92, 98       ; one cycle, signed 8-bit
        db      100, 98, 92, 83, 71, 56, 38, 20
        db      0, -20, -38, -56, -71, -83, -92, -98
        db      -100, -98, -92, -83, -71, -56, -38, -20
```

`wave` is used as LC directly because in the program map a Z80 address is its physical address. Elsewhere use MMU page × `0x2000` + (address AND `0x1FFF`).

A one-shot sound effect on channel 3, cutting off whatever it plays (channel 3 already enabled, STEP and VOL set). HL = physical address bits 15–0 of the sample (bits 23–16 = 0), DE = length in samples:

```asm
sfx:    ld      bc,AUD3_CTRL_P
        ld      a,AUD_CTRL_ONESHOT_M    ; 8-bit, interpolated, one shot
        out     (c),a
        ld      bc,AUD3_LC_P
        out     (c),l
        inc     b
        out     (c),h
        inc     b
        xor     a
        out     (c),a                   ; LC bits 23-16
        ld      bc,AUD3_LEN_P
        out     (c),e
        inc     b
        out     (c),d
        inc     b
        out     (c),a                   ; LEN bits 23-16 (A = 0)
        ld      bc,AUDSTART_P
        ld      a,0x08                  ; channel 3
        out     (c),a
        ret
```

Interrupt handler body for source 9: queue the next block on channel 0 when it has taken its registers.

```asm
aud_isr:
        push    af
        push    bc
        push    hl
        ld      bc,AUDSTAT_P
        in      a,(c)
        and     0x01                    ; channel 0 took its block?
        jr      z,.done
        out     (c),a                   ; W1C: clear CH bit 0
        ld      hl,(nextblk)            ; physical address bits 15-0 of the next block
        ld      bc,AUD0_LC_P
        out     (c),l
        inc     b
        out     (c),h
        inc     b
        xor     a
        out     (c),a
.done:  pop     hl
        pop     bc
        pop     af
        ei
        reti
nextblk: dw     0
```

Read a channel's position (low byte first, it captures):

```asm
getpos: ld      bc,AUD0_POS0_P
        in      l,(c)                   ; captures all three bytes
        inc     b
        in      h,(c)
        inc     b
        in      a,(c)                   ; bits 21-16
        ret
```

## Pitfalls and limits

- **Write all five channel registers before starting**: there are no reset values, and after a reset they keep the last program's settings.
- **LC and LEN are taken only at a block's start.** Writing them while a block plays changes nothing until its end (except the interpolation join). To change sound now, write LC/LEN then AUDSTART.
- Every byte acts when written: STEP half written can play one sample at a mixed pitch (a click); write STEP while stopped. Write the next block's LC/LEN right after the channel's AUDSTAT bit sets; a block shorter than the time to write the next cannot be queued that way.
- LEN counts **samples**; for 16-bit samples LC must be even.
- AUDSTART does nothing to a channel that is not enabled (AUDDMA bit, AUDEN, DMAEN).
- Four channels near full volume plus the idle beeper (−`0x2000`) can clip at the negative end: keep the sum of volumes moderate or set the beeper bit (port `0xFE` bit 4) to 1 while playing.
- Physical addresses, SRAM only, no range check (wrap at 4 MB; bit 21 ignored on the KS2).
- Memory: at most 8 word reads per output sample (under 1 MB/s) on memory cycle 4, which sound owns: playing never slows the CPU or the display.
- The copper writes these registers only with MOVEF (offsets above `0x0EF`).
- Port `0xFE` bit 4 (the beeper) is the only sound when no channel plays; `OUT (0xFE),A` sets the border too.
- AUDSTAT's clear-wins rule differs from DMXINT's set-wins rule (spec 13, AU2): a block taken in the same clock as the clearing write loses its interrupt.
