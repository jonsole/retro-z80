# Input: keyboards and joysticks

> retro-z80 reference for AI models writing Z80 code. Register tables between `<!-- gen:NAME -->` markers are generated from `fpga/regmap.def` by `python3 tools/llm_docs.py input`: never edit them by hand. Every ```asm block assembles on its own (`python3 tools/llm_docs.py --asm input`); general rules are in [system.md](system.md).

**Built on the KS2:** all of it (membrane, port `0xFE`, KEYMAP, KEYROW, KEYCON, PS/2 receiver and Spectrum key mapper, joysticks, Kempston). Confirmed on the board: the membrane and port `0xFE`, and PS/2 bytes injected from the PC (the bridge's `key_down`, `key_up`, `type_text`). A real PS/2 keyboard and the joysticks are tested in simulation only so far.

## What it does

The membrane (8 × 7 matrix: 40 Spectrum keys + 16 extra Next keys) is scanned and debounced in hardware. A PS/2 keyboard's raw scan-code bytes go into a 16-byte FIFO, and are also mapped onto the Spectrum matrix. Two joystick ports read Atari sticks or Mega Drive 3/6-button pads. Everything is polled except the PS/2 keyboard (source 17, KEYB).

## Enable

| What | Default after reset | Notes |
|------|---------------------|-------|
| Membrane, KEYMAP, port `0xFE` | Always on | No enable |
| PS/2 into the FIFO | KBCON.EN = 0 after reset; **the boot ROM sets it to 1** for programs | Turning EN off empties the FIFO |
| PS/2 keys on port `0xFE` / KEYROW | KEYCON.PS2MAP = 1 | Receiver runs while KBCON.EN or PS2MAP |
| Extra Next keys on port `0xFE` as Spectrum pairs | KEYCON.KXMAP = 1 | |
| Port `0xFE` bit 6 | KEYCON.EAR6 = 1 | |
| Mega Drive pads | JOYCON.MD1 / MD2 = 0 (Atari stick) | Set MDn to read a pad on port n |

KEYCON reset value is `0x07`.

- Low-byte-only ports (any high byte): `0x1F` (KEMPSTON = JOY1), `0x62` (KBDATA), `0xFE` (keyboard rows / border + beeper). hw.inc: `KEMPSTON_PORT`, `KBDATA_PORT`, `ULA_PORT`.
- KEYMAP0–6 (`0x10`–`0x16`): column c of the membrane, bit r = row r, **1 = pressed**. Membrane only (no PS/2, no KXMAP).
- KBSTAT.COUNT (4–0): bytes waiting, 0–16. KBSTAT.TXBUSY (7): a byte is being sent.
- KBDATA: reading takes a byte; empty reads `0x00` and takes nothing. Check COUNT first.
- KBIRQ: DATA (0) live = FIFO not empty; PARITY, FRAME, OVERFLOW, TIMEOUT sticky W1C. KBIRQEN same layout.
- KBSEND: ignored while TXBUSY; keyboard answers `FA` into the FIFO; 15 ms without answer → TIMEOUT.
- JOY1/JOY2 and KEMPSTON: **1 = pressed**. JOYCON bits 4–7 (SIXn, MDPRESn) are read only. JOYnX: X, Y, Z, MODE of a 6-button pad (0 otherwise).
- Unused `0x17`–`0x1E`, `0x69`–`0x6A`, `0x6E`–`0x6F` read `0xFF`.

## Data structures

**Port `0xFE` read** (`IN A,(0xFE)` puts A on A15–A8; `IN r,(C)` with C = `0xFE` puts B there). A row is selected when its address line is **0**; selected rows are ANDed (0 = pressed in any). High byte `0x00` reads all rows; so does the page form `0xFE00` and register page `0x00FE`.

| Row | High byte | Bit 0 | Bit 1 | Bit 2 | Bit 3 | Bit 4 |
|-----|-----------|-------|-------|-------|-------|-------|
| 0 | `0xFE` | CAPS SHIFT | Z | X | C | V |
| 1 | `0xFD` | A | S | D | F | G |
| 2 | `0xFB` | Q | W | E | R | T |
| 3 | `0xF7` | 1 | 2 | 3 | 4 | 5 |
| 4 | `0xEF` | 0 | 9 | 8 | 7 | 6 |
| 5 | `0xDF` | P | O | I | U | Y |
| 6 | `0xBF` | ENTER | L | K | J | H |
| 7 | `0x7F` | SPACE | SYMBOL SHIFT | M | N | B |

Bits 5 and 7 read 1; bit 6 = KEYCON.EAR6. KEYMAPc bit r is the same key as row r bit c, but 1 = pressed.

**Extra Next keys** (KEYMAP5, KEYMAP6, bit = row):

| Row (bit) | KEYMAP6 key | Port `0xFE` with KXMAP | KEYMAP5 key | Port `0xFE` with KXMAP |
|-----------|-------------|------------------------|-------------|------------------------|
| 0 | Cursor up | CS+7 | EXTEND MODE | CS+SS |
| 1 | GRAPH | CS+9 | CAPS LOCK | CS+2 |
| 2 | INV VIDEO | CS+4 | TRUE VIDEO | CS+3 |
| 3 | EDIT | CS+1 | BREAK | CS+SPACE |
| 4 | `"` | SS+P | `;` | SS+O |
| 5 | `.` | SS+M | `,` | SS+N |
| 6 | Cursor right | CS+8 | DELETE | CS+0 |
| 7 | Cursor down | CS+6 | Cursor left | CS+5 |

CS = CAPS SHIFT, SS = SYMBOL SHIFT.

**JOY1, JOY2, KEMPSTON** (1 = pressed):

| Bit | 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
|-----|---|---|---|---|---|---|---|---|
| JOYn | START | A | Fire 2 / C | Fire 1 / B | Up | Down | Left | Right |
| JOYnX | 0 | 0 | 0 | 0 | MODE | Z | Y | X |

Mega Drive pads are read in a burst every 2.048 ms; Atari sticks continuously.

**PS/2 → port `0xFE` map (PS2MAP):** letters, digits (main row and keypad), Enter, Space → same key; Shift → CAPS SHIFT; Ctrl, Alt → SYMBOL SHIFT; Backspace → CS+0; cursors → CS+5/6/7/8; Esc → CS+SPACE; Caps Lock → CS+2; Tab → CS+SS; `, . ; ' / - =` → SS+N, M, O, 7, V, J, L. Others map to nothing. Per key: Shift+`,` gives CS+SS+N, not `<`.

**PS/2 FIFO bytes** are scan code set 2, raw: `1C` = A down, `F0 1C` = A up, `E0 75` = cursor up, `E0 F0 75` its release, `AA` self-test passed, `FA` acknowledge.

## Recipes

Read one Spectrum key (SPACE = row 7, bit 0):

```asm
        ld      a,0x7F                  ; A15-A8 = 0x7F: row 7 only
        in      a,(ULA_PORT)
        rra                             ; bit 0 into carry
        jr      nc,pressed              ; 0 = pressed
        ret
pressed:
        ret
```

Whole membrane into 7 bytes at `keys` (1 = pressed), columns 0–6:

```asm
        ld      hl,keys
        ld      bc,KEYMAP0_P            ; register 0x10 of page 0x00
.col:   in      a,(c)
        ld      (hl),a
        inc     hl
        inc     b                       ; next column register
        ld      a,b
        cp      KEYMAP6+1
        jr      nz,.col
        ret
keys:   ds      7
```

Rows by memory (the register page mapped at `0xE000`, as in [system.md](system.md)):

```asm
SREG    equ     0xE000                  ; register page in window 7
        ld      a,(SREG+KEYROW0+7)      ; row 7 alone: SPACE, SYMBOL SHIFT, M, N, B
        bit     0,a
```

Joystick 1, Kempston style:

```asm
        in      a,(KEMPSTON_PORT)       ; = JOY1, 1 = pressed
        bit     4,a                     ; Fire 1
        jr      nz,fire
        and     0x0F                    ; directions: Up 3, Down 2, Left 1, Right 0
        ret
fire:   ret
```

Enable a Mega Drive pad on port 1, then read its extra buttons:

```asm
        ld      bc,JOYCON_P
        ld      a,JOYCON_MD1_M
        out     (c),a
        ld      bc,JOY1X_P
        in      a,(c)                   ; X 0, Y 1, Z 2, MODE 3 (6-button pad only)
```

Drain the PS/2 FIFO with `INIR` (from spec 12):

```asm
        ld      hl,buf
        ld      bc,KBSTAT_P
        in      a,(c)
        and     KBSTAT_COUNT_M          ; bytes waiting, 0-16
        jr      z,.none
        ld      b,a                     ; count
        ld      c,KBDATA_PORT           ; port 0x62, any high byte
        inir
.none:  ret
buf:    ds      16
```

Decode make/break (from Example 8-2): track `F0` (release) and `E0` (extended) prefixes:

```asm
.wait:  ld      bc,KBSTAT_P
        in      a,(c)
        and     KBSTAT_COUNT_M
        jr      z,.wait
        in      a,(KBDATA_PORT)         ; take one byte
        cp      0xF0
        jr      z,.release
        cp      0xE0
        jr      z,.ext
        ld      e,a                     ; E = key code; D bit 0 = release, bit 1 = E0
        ld      d,0
        ret
.release:
        set     0,d
        jr      .wait
.ext:   set     1,d
        jr      .wait
```

Game keys without CAPS SHIFT for cursors: turn off KXMAP and read KEYMAP5/6 directly:

```asm
        ld      bc,KEYCON_P
        ld      a,KEYCON_EAR6_M|KEYCON_PS2MAP_M ; KXMAP off
        out     (c),a
        ld      bc,KEYMAP6_P
        in      a,(c)                   ; bit 0 up, 6 right, 7 down (1 = pressed)
        ld      bc,KEYMAP5_P
        in      b,(c)                   ; bit 7 left
```

For text input prefer the ROM calls GETC (`RST 10h`), POLLC (`RST 20h`), GETLINE (`RST 28h` function `0x05`): they merge both keyboards and the serial link and return ASCII and key codes ([system.md](system.md)).

## Pitfalls and limits

- Port `0xFE` decodes the whole low byte: only `0xFE` works (a Spectrum's other even ports do not). Kempston likewise is `0x1F` only.
- `IN A,(0xFE)` uses A as the row select: load A first. `IN A,(0x00)`-style page reads also use A as the register number.
- Polarity differs: port `0xFE`/KEYROW 0 = pressed; KEYMAP, JOYn, KEMPSTON 1 = pressed.
- KBDATA reads have a side effect: never `INC (HL)`/`BIT` on it through the register page; an empty read returns `0x00`. The ROM's console calls also read KBDATA (GETC, POLLC, GETLINE): don't mix them with your own KBDATA reader, or set CONMODE to take keys only from the serial link.
- Bytes typed through the bridge (`type_text`, `key_down`) arrive as PS/2 bytes: they reach KBDATA (if KBCON.EN) and port `0xFE` (if PS2MAP), never KEYMAP0–6. A program that reads only KEYMAP cannot be driven from the bridge. `type_text`'s default 40 ms hold suits a program polling once a frame.
- Membrane ghosting: three keys at three corners of a rectangle make the fourth look pressed (no diodes).
- KEYMAP needs no row select and is one `IN` per column; KEYROW needs the register page mapped.
- A key held on PS/2 is cleared from the map on reset, PS2MAP off, receiver stop, or `AA`. While KBSEND sends, nothing is received.
- Which physical joystick connector is port 1 is not yet confirmed on the board.
