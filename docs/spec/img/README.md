# Figures for the specs

The specs' drawings follow the guide's figure style (`docs/guide/img/README.md`). Name them `<spec file>-<number>-<slug>.svg`; the number is the figure number in the spec (spec 14's Figure 14-1 is `dma-engine-1-...`).

| Script | Figures |
|--------|---------|
| `tools/guide_figures/dmxpipe.py` | `dma-engine-1-group-today.svg`, `dma-engine-2-options.svg`: version 1's DMA engine (spec 14 before ticket #103, sections 6.1 and 6.2). The blitter spec no longer uses them; kept for its history until removed |
